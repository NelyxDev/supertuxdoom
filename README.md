Super Tux Doom is a standalone, retro-style boomer shooter designed as a commercial/standalone IWAD with strict Vanilla Doom compatibility and classic 90s design principles.

---

## What is Super Tux Doom?

Super Tux Doom is built to bring back the pure dopamine of 90s FPS chaos. Developed to run seamlessly on the Nelyx Engine (as well as standard Vanilla-compatible Doom source ports, that is basically everything), that offers a very faithful, light for any modern hardware and easy out of the box experience.

---

## Technical Overview

* **Format:** Standalone IWAD / Standalone Game
* **Compatibility Target:** Vanilla Doom II rulesets
* **Primary Engine:** Nelyx Engine
* **Development Focus:** Pure boomer shooter mechanics and high performance on low-end hardware.

## How to Play

### Running with Nelyx Engine
When the IWAD comes out:
1. Download the latest build of **Super Tux Doom** (`tuxdoom.wad`).
2. Place `tuxdoom.wad` inside the `data/` folder of **Nelyx Engine**.
3. Launch the engine executable.
